# La mia film checklist — GitHub Pages

## Pubblicazione
1. Estrai tutti i file dello ZIP.
2. Apri il repository GitHub che vuoi usare (puoi crearne uno chiamato `Film-Checklist`).
3. Carica **tutti** i file e le cartelle presenti qui nella cartella principale del repository, mantenendo i nomi.
4. In GitHub vai su **Settings → Pages**.
5. In **Build and deployment** seleziona **Deploy from a branch**, branch `main`, cartella `/(root)`, quindi **Save**.
6. Attendi la pubblicazione: l'indirizzo sarà `https://TUO-USERNAME.github.io/NOME-REPOSITORY/`.

## Installazione sul telefono
Apri il link pubblicato con Chrome su Android, premi il menu ⋮ e scegli **Aggiungi a schermata Home** oppure **Installa app**.

## Dati e progressi
I film visti e i voti vengono salvati nel browser/dispositivo tramite memoria locale. Non vengono sincronizzati automaticamente tra dispositivi o browser. Usa **Esporta progressi** per creare una copia JSON e **Importa progressi** per ripristinarla.

## File inclusi
- `index.html`: webapp completa con la lista dei 200 film.
- `manifest.webmanifest`: configurazione installazione PWA.
- `sw.js`: cache offline.
- `icon-192.png`, `icon-512.png`: icone.
- `.nojekyll`: configurazione GitHub Pages.
